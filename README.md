# React Contact Cards

A React single-page application for creating users and dynamically displaying contact cards.

## Assignment requirements demonstrated

- React SPA
- User input form
- Dynamic contact card creation
- Parent `UserList` component
- Reusable `ContactCard`
- Modular components folder
- Props between components
- State with `useState`

## Component structure

App
├── ContactForm
└── UserList
    └── ContactCard

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.
